# CalcSolver 视觉重做 · 2026-09-30

## 本轮目标

用户要求重新开发前端视觉，强调有设计感、减少 AI 模板感。后续回复继续强调设计完成度，没有指定具体配色。本轮据此采用纸白、石墨黑与少量明黄的工具视觉，保留网站的计算与学习用途。

改版前已检查实际首页、现有 Astro 组件、样式、文章与活动交互。上一版的米白、墨绿、衬线大标题和双栏介绍已经形成基础，本轮重新处理字体比例、工具位置和内容层级。

## 视觉与实现

- Manrope 负责标题和正文，IBM Plex Mono 用于真实算式、显示屏和快捷键。数学分类符号沿用数学字体的形态。
- 桌面首页采用介绍、实际计算器、可点击算式参考的不同宽度布局。计算器为石墨机身和灰色按键，等号为明黄，屏幕保留清晰的 LCD 层级。
- `1/4 = 0.25 = 25%` 的等值示意关联实际文章；四块等分图准确标出其中一块。图形用于解释数学内容。
- 数学指南以分类符号、标题和文章目录形成层级，使用留白和实际内容分组的分隔线。阅读页突出答案、公式和表格。
- 活动目录、播放器、本站小游戏、共享导航和页脚统一字体、焦点与配色。本站游戏保留识别数字级别、蛇和食物的功能颜色。
- 计算器样式独立到 `src/styles/calculator.css`，继续使用现有 Astro 静态架构和事件接口。
- 320px 手机科学键改为四列，其他手机与平板断点按宽度调整布局。按钮反馈和进入动画尊重减少动态效果的设备设置。

现有导航名称、文章路由、canonical、sitemap、计算引擎、活动数据和游戏逻辑均保持兼容。字体继续由 Google Fonts 提供，与现有隐私声明相符。

## 验证

- `npm run verify` 通过：28 个 Astro 文件无错误、警告或提示，28 项行为测试通过。
- 生产构建生成 41 个 HTML 页面，720 个站内链接和 38 个 sitemap 地址验证通过。
- 实际浏览器中三组示例分别得到 `14`、`18.75`、`9`，`sin(30)` 得到 `0.5`。除零显示错误并设置 `aria-invalid`。
- 1440px 桌面完整显示实际计算器。320px、375px 手机和 768px 平板首页无横向溢出；320px、375px 科学按键的宽高最小值为 44px。
- 手机导航能够展开并访问分类页；分类页与 `6/7` 循环小数文章无横向溢出，答案显示近似符号与正确数值。
- `0000` 打开 132 项活动目录。代码搜索得到单项结果，无匹配搜索显示空状态，本站来源显示两项。
- 2048 移动后棋盘改变并生成新格。Snake 能开始与暂停。退出目录关闭对话框并释放 iframe。
- 已在现有生产预览服务器 `http://127.0.0.1:4321/` 验证构建结果。本轮没有发布远程部署。
