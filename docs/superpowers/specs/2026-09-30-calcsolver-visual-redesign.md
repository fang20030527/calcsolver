# CalcSolver 前端视觉重设计（待确认）

## 目标与当前问题

用户要求重新开发前端视觉，摆脱通用 AI 模板感，形成有辨识度的设计。当前版本已经部署在 https://calcsolver-info.pages.dev/ 。本次保留数学工具与内容的功能范围，重做其呈现方式。

现有页面以浅蓝导航、居中介绍、独立居中计算器、三列等宽功能卡片组成，视觉层级重复。计算器的红、橙、蓝按键缺少统一色彩逻辑；正文灰蓝色偏淡，介绍区占用较多首屏高度。

## 方向比较

1. **推荐：书刊式数学工具。** 暖白纸色、墨绿文字、陶土橙重点色，书刊标题与清晰的无衬线正文搭配。首页采用左右不同宽度的布局，数学指南呈现为内容目录。优点是温和、耐看，适合工具与教学内容并存；不会像纯后台工具那样生硬。
2. **精密仪器风格。** 冷白、石墨灰与少量工业黄，紧凑的无衬线标题，计算器占据主画面。工具效率强，但文章页的阅读氛围弱于方向 1。
3. **深色数字工作台。** 深灰底与绿色显示屏，计算器和功能区集中在一屏。辨识度来自工具本身，适合高频计算，但长篇文章需要另设明亮阅读界面。

## 推荐方向的视觉规格

- 背景：暖白 `#F3F0E8`，内容表面 `#FAF8F2`。
- 主文字：墨绿 `#293B32`，次级文字 `#626B62`，分隔线 `#D6D8CC`。
- 重点色：陶土橙 `#B74D2B`，用于可点击示例、关键结果和主要按钮；不同时使用多种鲜艳的功能色。
- 标题：Source Serif 4，用于首页大标题、文章标题与少量章节标题。
- 正文：DM Sans；计算器数字、算式与快捷键：IBM Plex Mono。
- 标题大小随设备调整，桌面首页约 64px，文章标题约 46px；手机首页约 40px，文章标题约 32px。正文以 15-17px 为主。
- 版心最大宽度约 1180px；文章正文保持约 720px 的阅读宽度。
- 圆角克制：小按钮约 4px，计算器机身约 14px。内容主要靠排版与留白组织。
- 分隔线仅用于导航、内容目录与实际分组，不铺装饰网格。无需背景光斑、渐变标题、浮动数学符号或装饰性编号。

## 首页与共享界面

- 导航保持 CalcSolver 字标及三个现有数学分类名称、链接，重做字重、颜色、间距与当前页状态。
- 首屏：左侧为自然的标题、简短用途介绍、可点击算式示例与进入指南的链接；右侧为真实计算器。计算器在桌面第一屏内完整可操作。
- 手机上缩短介绍区，计算器紧随其后；机身与按键适配 375px 宽屏，按键触摸尺寸至少 44px。
- 将首页重复的营销说明收拢成简洁的使用说明，保留科学函数说明、快捷键、Code Mode 提示与数学分类入口。
- 数学指南采用纵向目录：左侧分类标题和简介，右侧文章链接。减少等宽卡片，让主题名和文章内容成为层级依据。
- 页脚使用统一的暖白、墨绿配色，保留 About、Contact、Privacy Policy。

## 计算器与活动目录

- 保留真实输入框、全部数字和运算按键、科学函数、复制结果、清除、退格与键盘操作。
- 机身使用墨绿，显示屏使用浅灰绿，数字键使用暖白；运算键使用统一的深浅层级，等号键使用陶土橙。移除红、亮橙、蓝混用的按键方案。
- 开关、焦点、错误消息与展开后的科学键属于同一视觉系统，不能靠低对比的小字承担重要信息。
- 保留 Code Mode，`0000` 打开目录、`3001` 与 `3002` 打开本站游戏。
- 活动目录和播放器采用协调的深色墨绿界面，改善搜索、筛选、返回与退出按钮的可读性。130 条外部活动与 2 个本站游戏继续使用现有数据。
- 本站 2048 与 Snake 的外层排版、按钮、说明与计分区统一视觉语言；棋盘、Canvas 与游戏机制保持完整。

## 内容页、技术边界与验证

- 分类页、31 篇数学文章和信息页沿用现有 URL、导航标签、canonical、sitemap 与正文含义。
- 文章页改善标题、答案区、公式、步骤、表格与关联文章的层级，保留可访问的文字、链接与键盘焦点。
- 使用现有 Astro 静态架构，主要修改布局、组件标记与 CSS。数学引擎、游戏规则、目录数据和事件接口继续承担原有功能。
- 简短进入动画与按键反馈采用 CSS，尊重 `prefers-reduced-motion`；不引入动画框架或装饰性大型资源。
- 新字体仍使用现有 Google Fonts 方式；隐私说明中关于外部字体服务的描述保持准确。
- 验证 `npm run verify`，并在浏览器检查桌面与 375px 手机首页、展开科学键、Code Mode、目录搜索与退出、分类和文章页、本站游戏。
- 保留可供审阅的截图和构建包。上线更新使用现有 Cloudflare Pages 项目；`calcsolver.info` 的名称服务器激活属于现有未完成事项，本次设计确认不代替域名账户授权。

## 自检

- 视觉方向、颜色、排版、组件范围、移动布局和验收方式均明确，没有待补实现决策。
- 这是现有产品的视觉重做；内容地址、计算器与游戏交互仍有明确保留边界。
- 推荐方向与两种备选的差异集中在视觉与阅读体验，避免增加新的产品功能。
- 本文处于待确认状态；用户选定方向后再进行实现。
