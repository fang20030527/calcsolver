# calcsolver.info 复刻设计（已确认）

用户已确认本方案，并选择 Cloudflare Pages 作为部署平台。

## 目标

在当前仓库实现可独立构建和部署的 CalcSolver.info 网站，复现 calcsolver.net 的主要外观、计算器、Code Mode 和游戏目录体验。品牌链接、canonical、sitemap 和部署说明统一使用 `https://calcsolver.info`。

## 方案比较

1. **推荐：静态网站，Astro + TypeScript。** 页面直接输出 HTML，计算器和游戏目录在浏览器运行。适合数学内容 SEO；可部署 Cloudflare Pages 或 Vercel；没有数据库、服务器维护或登录依赖。
2. **WordPress + Kadence。** 接近参考站的技术栈，适合频繁使用后台编辑文章；需要额外托管、主题和插件维护。
3. **重新设计工具平台。** 保留产品机制但改变外观；可扩展性强，和本次“复刻”的目标距离更远。

选择方案 1，并保持原站页面视觉，不另做风格改版。

## 页面与视觉

- 英文页面；浅蓝导航、蓝色 CalcSolver 字标、三个数学分类导航。
- 首页包含介绍、居中的深色实体计算器、用途说明、三个文章分类、页脚。
- 计算器复现灰色显示屏、红色清除键、橙色运算键、深色数字键和 Code Mode 开关。
- 活动目录是铺满视口的深色界面，顶部提供搜索、游戏源选择、数量与 Exit；卡片显示缩略图、名称和四位编号。
- 播放界面包含游戏名称、返回目录、退出、全屏和推荐卡片。
- 桌面与 375px 宽手机都能操作；触摸目标、键盘焦点和减少动画偏好均受支持。
- 数学分类页、对应文章页、About、Contact、Privacy 均有可访问 URL。

## 交互与内容

- 普通计算模式支持四则运算、平方根、括号、运算优先级、键盘输入、回车计算、退格和清除；错误显示可理解的提示。
- 三角函数、对数、幂等科学函数提供可见入口，避免宣传与功能不一致。
- Code Mode 输入 `0000` 打开目录，输入存在的四位代码打开对应游戏；错误代码显示提示并允许重试。
- 搜索同时匹配名称与编号，支持清空、无结果状态、卡片加载失败的替代图。
- 已读取的参考站公共配置包含 130 条活动记录，第一版复现其目录与外部 iframe 加载方式。目录数量来自实际数据。
- 其他参考站服务器配置返回 403；第一版提供可扩展游戏源配置，不假装这些未取得的服务器已可用。
- 至少提供两个本站内置小游戏，保证第三方不可用时仍有实际可玩内容。
- 外部游戏包含加载提示、打开原始游戏地址与重试操作；跨域 iframe 加载不代表已经验证游戏内部正常，需在验收中区分。
- 数学文章按原有分类和主题撰写本站内容，分数转换显示准确答案、公式和简短说明。
- 首页不接入参考站的广告或统计账户。广告与分析服务可在后续接入用户自己的账户；本次交付完整可用的网站。

## 架构

- Astro：静态布局、首页、分类、文章和信息页面。
- TypeScript：计算解析器、计算器状态、目录搜索、Code Mode、游戏播放器、内置小游戏。
- 数据文件：游戏目录与来源配置；数学文章元数据和内容。
- CSS：共享颜色与间距变量、计算器、目录、播放器、移动端样式。
- 构建产物：`dist/`，包括 HTML、资源、robots.txt、sitemap.xml 和 404 页面。
- 计算表达式使用受限制的数学解析器，输入不会通过 JavaScript `eval` 执行。
- iframe 只接受配置中允许的 HTTPS 地址；本站小游戏使用本地路径。

## 验收

1. 项目可安装、运行、本地预览和构建。
2. 科学运算、优先级、负数、错误表达式与非法输入有针对性的测试。
3. 浏览器验证首页按键、键盘、0000、单游戏代码、搜索、退出与返回、内置小游戏。
4. 检查桌面和手机布局，没有页面横向溢出。
5. 文章与分类链接有效；canonical 和 sitemap 使用 `.info`。
6. 留下预览地址、构建结果和部署说明，明确区分外部游戏目录可用与全量游戏可玩。

## 部署边界

交付代码、构建产物与 Cloudflare Pages/Vercel 配置说明。公开上线和域名绑定需要用户的托管平台与 DNS 账户；购买域名本身不提供这些权限。若已有可用连接或会话，可在代码验收后继续部署；否则需要用户提供平台选择并完成账户登录。
